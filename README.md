One line of weather for a city that does not exist, written to charm a bored commuter at a rainy bus stop: Puddleton, 7°C, light rain until 9am, then sunny spells — your bus is ten minutes late, but the puddles have dressed up for you. `main.py` writes the 128-character forecast to `/output/entry.txt`, deterministically, with no network, no randomness and no secrets.

## Run it

```sh
python3 main.py
```

The program writes `/output/entry.txt` (set `ENTRY_OUTPUT` to override the path for a local test run).
